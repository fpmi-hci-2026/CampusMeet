# Диаграммы CampusMeet: исходники и читаемая публикация

В проекте 35 основных SVG: 29 схем ЛР3 и 6 схем ЛР4. Для длинных моделей созданы отдельные SVG-фрагменты; портал переключает их без сетевой загрузки данных. Полная схема остается доступна по кнопке открытия в новой вкладке.

## Компоновка

- Требования ЛР4 разложены на независимые цепочки «роль → история → вариант использования».
- ER-модели и плотные структурные схемы разделены на фрагменты с отдельными полосами связей. Блок справа с пометкой «Ссылка на сущность» обозначает тот же объект, который полностью описан в собственном фрагменте. Повтор имени не создает новую сущность.
- У связей сохранены подписи, направления и UML-маркеры: наследование, композиция и агрегация. Цветовые категории EventStorming / Event Modeling сохранены.
- У activity/sequence сохранена исходная UML-топология; сообщения, пересекающие линии жизни, и соединения ветвей являются частью нотации. Удалены служебные предупреждения, задан непрозрачный фон и исходный масштаб с основным текстом 16 px.
- Просмотрщик показывает исходный размер вместо принудительного уменьшения. Обычное колесо и свайп одним пальцем прокручивают схему; масштаб меняется только пинчем или Ctrl + колесом. Перетаскивание отключено. Длинные модели переключаются по фрагментам. Полноэкранный режим также открывается в масштабе 1:1; «Вписать» применяется только по явному нажатию.

## Источники

- `.puml` — семантические определения UML и C4. Из них не удалялись сущности и связи; размер шрифта поднят, устаревшая опция handwritten удалена.
- `puml/layout-models.json` — редактируемая модель опубликованной компоновки ЛР3: все сущности, строки атрибутов/операций, области, связи, направления и типы маркеров. Она первоначально извлечена из семантических групп ранее скомпилированных SVG. SHA-256 связывает ее с текущим `.puml`; при изменении требований обновляются оба файла.
- `.dot` и `.puml` в `lab4/` описывают исходный граф требований и БД; его фиксированную SVG-компоновку строит `scripts/diagram_layout.py`. Это не результат автоматической перекомпиляции PlantUML.

## Пересборка

Из CampusMeet; соседний CampusMeet-Server нужен только для синхронизации ЛР4:

```bash
python3 scripts/rebuild-diagrams.py
python3 scripts/sync-lab4.py
python3 scripts/paginate-diagrams.py
python3 scripts/check-diagrams.py
python3 scripts/sync-reports.py
python3 scripts/check-lab4.py
```

Для точного измерения текста при генерации используется Pillow и локальный Arial (macOS) / DejaVu Sans (Linux); при отсутствии Pillow есть приближенный резервный расчет. Финальный вариант необходимо проверить `check-diagrams.py` и визуально. Сам аудит сохраненных схем не требует внешних библиотек, Graphviz, PlantUML, Docker или доступа в интернет.

Проверка фиксированных моделей контролирует пересечения карточек и подписей, выход текста за границы, пересечения соединений между собой и прохождение через чужие блоки/подписи. Для девяти схем activity/sequence отдельно проверяются подписи и масштаб; допустимые UML-пересечения линий жизни и точек слияния не считаются ошибками.
