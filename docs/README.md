## Интерактивный просмотр отчетов

* **Локальный запуск GitHub Pages:**
  Откройте файл `docs/index.html` в любом современном веб-браузере (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge). Портал поддерживает интерактивное переключение вкладок, визуализацию диаграмм Mermaid, темный режим и галерею персонажей с фотопортретами.
* **База знаний GitHub Wiki:**
  Полная вики-документация синхронизирована в каталоге `../wiki/` ([wiki/Home.md](../wiki/Home.md)).
* **База данных SQL:**
  Исполняемый DDL-скрипт с 10 таблицами и демонстрационными данными расположен в репозитории серверного приложения: [CampusMeet-Server / database/schema.sql](https://github.com/fpmi-hci-2026/CampusMeet-Server/blob/main/database/schema.sql).
