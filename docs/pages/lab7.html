01. Архитектура сервера и стек технологий

Серверная часть платформы CampusMeet спроектирована по модульному принципу в репозитории CampusMeet-Server на выделенной ветке lab7.

Технологический стек

Ключевые компоненты рантайма

  • FastAPI 0.110+: Высокопроизводительный асинхронный ASGI-фреймворк с автоматической генерацией Swagger UI (/docs) и ReDoc (/redoc).
  • Pydantic v2.6+: Валидация входных DTO на Rust с нулевым накладным расходом.
  • Uvicorn (Standard): Асинхронный сервер с циклами uvloop и поддержкой HTTP/1.1 и WebSockets.
  • SQLite 3 (WAL mode) / PostgreSQL 16: Надежное транзакционное хранилище с внешними ключами и каскадными операциями.
  • RFC 7807 Problem Details: Унифицированная обработка всех исключений API.
Бизнес-логика

Инженерные особенности ЛР7

  • Предотвращение овербукинга: Атомарная проверка вместимости аудитории в транзакции базы данных.
  • Очередь ожидания (Waitlist): Приоритетное авто-продвижение ожидающего участника при отмене чужого билета.
  • Идемпотентность (RFC 7231): Защита от двойного списания квот через заголовок Idempotency-Key.
  • HMAC-SHA256 подпись: Векторный QR-код с динамическим хешем, проверяемый онлайн и офлайн.
