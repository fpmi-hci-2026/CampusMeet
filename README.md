# CampusMeet / EventHub

## Project Name
**CampusMeet (EventHub)** — Кроссплатформенная экосистема для локальных студенческих и IT-сообществ, обеспечивающая полный цикл организации митапов, хакатонов и конференций: управление квотами мест, офлайн-валидация билетов с динамическими QR-кодами, модерация заявок докладчиков и нетворкинг на площадке.

## Description
Проект **CampusMeet** разработан в рамках дисциплины «Проектирование человеко-машинных интерфейсов» (ПЧМИ, ФПМИ БГУ, 2025–2026 уч. год). Система решает критическую социальную проблему хаотичной организации университетских и локальных мероприятий, ликвидируя очереди на стойках регистрации, сбои при отсутствии интернета на площадке и «синдром потерянных регистраций» при использовании традиционных Google-форм. Архитектура объединяет десктопный Web-кабинет для комплексного администрирования событий и мобильное нативное приложение (iOS/Android) с Offline-First доступом к билету, оптическим сканером прохода (<500 мс) и интерактивным таймингом «Моя программа».

## Usage
### Целевые пользовательские сценарии экосистемы (Target Use Cases)

> **Примечание:** Описанные ниже сценарии отражают проектируемое целевое взаимодействие пользователей в рамках разработанных Use Case и сценариев Лабораторной работы №1. Программная реализация пользовательских интерфейсов осуществляется поэтапно в рамках Лабораторных работ №5–7.

1. **Для студента-слушателя:**
   * Откройте мобильное приложение CampusMeet, выберите актуальное событие в ленте афиши и нажмите *«Зарегистрироваться»*.
   * Билет с динамическим криптографическим токеном сохраняется в памяти устройства.
   * На входе в корпус приложите экран смартфона к сканеру волонтера — верификация срабатывает моментально даже без подключения к сотовой сети или Wi-Fi.
   * Формируйте персональный трек докладов и получайте push-уведомления за 15 минут до начала выступлений.

2. **Для волонтера стойки регистрации:**
   * Авторизуйтесь под учетной записью волонтера в мобильном приложении и откройте экран *«Сканер билетов»*.
   * Направляйте камеру на экраны подходящих участников: зеленый световой экран и тактильная вибрация подтверждают успешный проход, исключая скопление людей у дверей.

3. **Для организатора мероприятий:**
   * Войдите в веб-кабинет CampusMeet-Web.
   * Создайте карточку митапа, укажите лимит квоты мест и адрес площадки (интеграция с Nominatim OpenStreetMap API).
   * Проверьте дату события на пересечение с государственными праздниками через Nager.Date API.
   * Модерируйте заявки спикеров в разделе CFP и формируйте программу выступлений.
   * Отслеживайте график явки в день мероприятия и рассылайте экстренные Push-сообщения при любых изменениях в тайминге.
